# Yawn detection measured on YawDD

Generated by `cd data && uv run python -m pulsar_vision.yawdd` on 2026-11-14T17:47:32Z. Every number below comes from
`yawn_metrics.json`, produced by that run. It is not a medical device and this is not a clinical validation.

## What was measured

- **Data**: YawDD, 349 videos of drivers in cars (640x480, 29.97, 30.0 fps, no audio). The *Mirror* set has one label per video, taken from the file name: 105 Normal, 100 Talking, 102 Yawning and 13 Talking&Yawning videos of 90 people. The *Dash* set has 29 longer videos with no labels in time.
- **Landmarks**: MediaPipe `FaceLandmarker` (VIDEO mode, Python 1.2.3) with the model file the browser loads (`frontend/public/mediapipe/face_landmarker.task`), on one frame in every 2: 14.985, 15.0 fps, G1's minimum frame rate. 144167 frames in total.
- **Feature** (`inner_lip_gap_over_outer_eye_corner_distance_2d_px`): dist(upper_inner_lip, lower_inner_lip) / dist(right_eye_outer, left_eye_outer), 2D Euclidean distance in pixels (x * image_width, y * image_height).
  Landmark indices: upper_inner_lip = 13, lower_inner_lip = 14, right_eye_outer = 33, left_eye_outer = 263.
- **Detector**: the mouth is open from the first frame with the ratio at or above the threshold and stays open while it is at or above `release factor x threshold`; an open stretch that lasts at least the minimum duration is one yawn. Frames with no face are missing, not zero; a stretch survives at most 0.25 s without a confirming frame (fixed, not searched).
- **Two variants**: *absolute* compares the ratio with the threshold; *relative* compares it with a per-video baseline (median of the first seconds) plus the threshold.
- **Validation**: 5 folds grouped by subject (camera + sex + participant number), stratified by sex. Threshold, minimum duration, release factor (and baseline window) are searched on the train folds only, maximising `recall_yawning - 0.5 * (false_alarm_talking + false_alarm_normal), on videos`; the numbers below are from the test folds, pooled. No person is in both the train and the test side of a fold.

## Limits

- **Acted yawns.** The yawns were performed for the recording; acted yawns may be wider, longer or cleaner than spontaneous ones.
- **Drivers in cars, not a crew at a laptop.** The camera sits under the front mirror or on the dash, so the face is seen from the side and from above or below, in outdoor light (the dataset tables list sunny, cloudy and rainy). A laptop webcam is frontal, at another distance, in indoor light. The ratio is normalised by face size but not by head pose.
- **Labels are per video, not per frame.** We know a Yawning video contains a yawn, not when or how many. Recall is "at least one yawn found in the video"; a false alarm is "any yawn found in a Talking or Normal video". Yawn counts and timing are not validated.
- **Talking in YawDD is "talking or singing"** (dataset readme); the file name is the only label, so any other mouth movement inside a video is unknown to us.
- **The relative variant was tested on video starts, not on a calibration step.** Its baseline is the first seconds of each video, whatever the person was doing; in the product the baseline would come from a calm moment at session start. So this result does not tell how that variant would do with a proper baseline.
- **Small groups.** Sunglasses, beard and moustache groups have few videos; read their rows with the counts in view. Facial hair is taken from the file name, and the dataset tables list more bearded participants than the names mark.
- **One dataset, one camera geometry.** The thresholds are a measured starting point for G1, to be checked against the two G1 fixture videos and a real session; they are not validated for spaceflight.
- **Python, not the browser.** Same model file and the same formula, but the browser runs it in WebAssembly or on the GPU; small numeric differences are possible and no browser frame rate was measured here.
- **Hand over the mouth.** When a hand covers a yawn the landmarks under it are estimates; this case was not measured separately.
